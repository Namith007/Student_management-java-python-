# Student Management System

A basic console-based Student Management System implemented in both Java and Python.

## Features
- Add student
- View all students
- Search student by ID
- Delete student
- Menu-driven interface

## Technologies
- Java: OOP, ArrayList, Scanner
- Python: Lists, Dictionaries, Functions

## Run Java
```bash
javac Java/StudentManagement.java
java -cp Java StudentManagement
```

## Run Python
```bash
python Python/student_management.py
```
